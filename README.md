# Odin-recipes
This is a simple project built using HTML as part of The Odin Project curriculum.
## About 
The goal of this project is to create a recipes page structured with clean, semantic HTML. It focuses on organizing content using proper headings, lists, and images without relying on CSS or JavaScript.
## Skills Demonstrated 
-Structuring a webpage using semantic HTML elements
-Creating and organizing lists (ordered and unordered)
-Adding and formatting images 
-Writing clean, readable markup 
-Using Git and GitHub for version control
